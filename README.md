# 个人指数 ETF 定投决策助手

一个只在本地运行、用于指数估值展示和后续定投策略执行的 Streamlit 应用。

当前项目已完成本地数据湖、SQLite 用户设置、今日看板、指数详情页和策略设置页，并已接入两套定投法的估值状态和本月理论投入金额。

## 项目目标

1. 展示主要指数的最新价格、涨跌幅、PE、盈利收益率和 PE 百分位。
2. 根据 PE 百分位判断低估、适中或高估。
3. 根据估值状态和公式计算每月理论投入金额。
4. 后续记录实际 ETF 买入和卖出交易。
5. 不计算收益，实际收益以证券账户为准。

## 买入策略一：估值分位智能定投法

### 1. 估值分位区间

默认使用 5 年逐日 PE 百分位判断估值状态：

```text
PE 百分位 < 30%              -> 低估
30% <= PE 百分位 <= 70%      -> 适中
PE 百分位 > 70%              -> 高估
```

边界定义：

- `30%` 属于适中。
- `70%` 属于适中。
- 只有严格低于 `30%` 才属于低估。
- 只有严格高于 `70%` 才属于高估。

### 2. 每月投入公式

```text
每月投入 = 初始金额 × (10 / PE) ^ 放大器指数 × (1.01) ^ 月度
```

变量定义：

| 变量 | 定义 |
|---|---|
| `初始金额` | 每个指数单独配置的基础初始金额 |
| `PE` | 计算日最新有效 PE(TTM) |
| `放大器指数` | 低估时为 `1.5`，适中时为 `1` |
| `月度` | 从策略启用月份开始计算的月数，首个计算月为 `0` |
| `1.01` | 月度抗通胀增长系数 |

### 3. 按估值状态计算

#### 低估

```text
放大器指数 = 1.5

每月投入 = 初始金额 × (10 / PE) ^ 1.5 × (1.01) ^ 月度
```

低估状态允许计算和执行买入金额。

#### 适中

```text
放大器指数 = 1

每月投入 = 初始金额 × (10 / PE) × (1.01) ^ 月度
```

适中状态允许计算和执行买入金额。

#### 高估

```text
每月投入 = 0
```

高估状态停止买入，并进入卖出观察区。

### 4. 数据不可用

以下情况不计算投入金额：

- PE 缺失或小于等于 0。
- 5 年 PE 百分位不可用。
- PE 历史样本不足。
- 数据质量检查未通过。

页面应显示“数据不足，暂不计算”，不得使用默认金额替代。

### 5. 示例

假设：

```text
初始金额 = 1000 元
PE = 8
当前为低估
策略启用后的第 12 个月
```

则：

```text
每月投入 = 1000 × (10 / 8) ^ 1.5 × (1.01) ^ 12
         ≈ 1574.79 元
```

示例只用于验证公式，不代表投资建议。

## 买入策略二：均线偏离定投法

该策略使用指数点位相对 250 个交易日移动平均线（年线）的偏离程度，决定每月投入倍率。

### 1. 250 日均线

```text
MA250 = 最近 250 个交易日收盘点位的算术平均值
偏离度 d = (最新收盘点位 / MA250 - 1) × 100%
```

- `d < 0`：指数点位低于年线。
- `d = 0`：指数点位等于年线。
- `d > 0`：指数点位高于年线。

低于年线时增加投入，高于年线时减少投入。

### 2. 偏离度历史百分位

对历史逐日偏离度计算百分位。默认使用最近 5 年数据，10 年数据作为辅助展示和复核。

```text
偏离度百分位 < 30%              -> 低估
30% <= 偏离度百分位 <= 70%      -> 适中
偏离度百分位 > 70%              -> 高估
```

边界规则：

- `30%` 属于适中。
- `70%` 属于适中。
- 严格低于 `30%` 才属于低估。
- 严格高于 `70%` 才属于高估。

### 3. 偏离度投入倍率

| 偏离度历史百分位 | 状态 | 偏离度倍率 |
|---|---:|---:|
| `< 30%` | 低估 | `1.5×` |
| `30% - 70%` | 适中 | `1.0×` |
| `> 70%` | 高估 | `0×`，停止买入并进入分批卖出观察区 |

偏离度百分位越低，代表当前点位相对历史越偏向下轨，买入倍率越高。

### 4. 10 日波动率控制

先计算最近 10 个交易日的日收益率：

```text
日收益率 = 当日收盘 / 前一日收盘 - 1
```

再计算年化波动率：

```text
vol10 = 最近 10 个日收益率标准差 × sqrt(252) × 100%
```

波动率折扣：

| 10 日年化波动率 | 波动率折扣 |
|---|---:|
| `< 15%` | `1.00` |
| `15% - 25%` | `0.90` |
| `25% - 35%` | `0.75` |
| `35% - 50%` | `0.60` |
| `>= 50%` | `0.50` |

最终倍率：

```text
最终倍率 = 偏离度倍率 × 波动率折扣
```

最终投资金额：

```text
每月投入 = 基准月投额 × 最终倍率
```

当偏离度状态为高估时：

```text
偏离度倍率 = 0
最终倍率 = 0
```

波动率控制只用于降低买入金额，不改变卖出判断。

### 5. 示例

假设：

```text
基准月投额 = 1000 元
偏离度百分位 = 20%
10 日年化波动率 = 30%
```

则：

```text
偏离度倍率 = 1.5
波动率折扣 = 0.75
最终倍率 = 1.5 × 0.75 = 1.125

每月投入 = 1000 × 1.125 = 1125 元
```

### 6. 数据不可用

以下情况不计算投入金额：

- 收盘点位或 MA250 不可用。
- 250 日均线历史样本不足。
- 偏离度历史百分位样本不足。
- 10 日收益率数据不足。
- 数据质量检查未通过。

## 数据湖使用

前端：

- 未建湖：点击“初始化数据湖”，以 `full` 模式生成完整历史。
- 已建湖：点击“增量更新数据”，以 `incremental` 模式拉取新增日期。

CLI：

```powershell
# 初始化完整数据湖
D:\code\Fourty\.venv\python.exe scripts\build_lake.py --mode full

# 增量更新全部指数
D:\code\Fourty\.venv\python.exe scripts\build_lake.py --mode incremental

# 只更新指定指数
D:\code\Fourty\.venv\python.exe scripts\build_lake.py --mode incremental --indexes hs300,csi500

# 查看数据湖指数
D:\code\Fourty\.venv\python.exe scripts\build_lake.py --list
```

每次运行都会：

1. 保存 raw 原始 Parquet。
2. 写入 staging。
3. 合并为 curated 年度 Parquet。
4. 生成 derived 指标。
5. 写入 manifest、state、revision 和质量报告。

### 行情发布时序

数据湖区分正式日线和盘中行情：

- A 股正式日线在 `18:00` 后检查。
- 港股正式日线在 `19:00` 后检查。
- 收盘前不请求当日正式日线，也不会把盘中数据写入 curated。
- 页面显示“当日收盘数据尚未发布”，日线仍使用最近已发布交易日。
- 盘中价格和涨跌幅单独保存到
  `data/lake/meta/intraday_quotes.json`，只作为页面浮层。

如果正式数据源在预期时间后仍未发布：

- 第一次等待 30 分钟重试。
- 第二次等待 60 分钟。
- 第三次等待 120 分钟。
- 第四次等待 240 分钟。

重试状态保存在 `data/lake/meta/state/index_daily.json`。

CLI 运行时会同步向标准错误输出进度，例如：

```text
[1/18] 正在获取 上证50
[2/18] 上证50 获取完成
```

## 软件日志

应用日志位置：

```text
data/app.log
```

日志使用 Python 标准库 `RotatingFileHandler`：

- 单文件最大 2 MB。
- 最多保留 3 个历史文件。
- 自动记录建湖、数据源、国债更新、设置保存等异常。
- 捕获主线程和后台线程的未处理异常。

日志格式：

```text
时间 | 级别 | 模块 | 错误信息和堆栈
```
## 数据质量规则

- 日期必须可以解析。
- 同一指数同一日期不得重复。
- PE 必须为正数才参与计算。
- 最新日期必须满足新鲜度要求。
- 异常跳变数据不得静默参与百分位计算。
- 缺少数据时必须显示“不可用”，不得使用默认值。

测试对照中，AKShare 与妙想数据差距较大时进行提醒，但最终口径以 AKShare 为准。
